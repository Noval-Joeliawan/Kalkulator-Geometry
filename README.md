# Kalkulator Geometri Terpadu (Dual Mode 2D & 3D)

Aplikasi kalkulator dan visualisasi geometri berbasis desktop yang dibangun menggunakan Python dan Tkinter. Aplikasi ini dirancang untuk membantu perhitungan matematis bangun datar dan bangun ruang dasar, dilengkapi dengan visualisasi sketsa teknis 2D serta render proyeksi 3D interaktif.

---

## 📌 Fitur Utama

- **Hitung Luas Bangun**: Mendukung berbagai bangun datar (Persegi, Persegi Panjang, Segitiga, Lingkaran, Jajar Genjang, Belah Ketupat, Layang-Layang, Trapesium, Oval) dan luas permukaan Tabung.
- **Hitung Keliling Bangun**: Perhitungan keliling presisi untuk seluruh bangun geometri yang didukung.
- **Fungsi Invers (Reverse Calculation)**: Menghitung parameter dimensi asal (panjang sisi, jari-jari, alas, atau tinggi) jika nilai luas atau keliling telah diketahui.
- **Dual Mode Visualisasi (2D & 3D)**:
  - **Mode 2D (Sketsa)**: Menampilkan sketsa teknis bangun datar lengkap dengan garis panduan ukuran (panjang, lebar, tinggi, jari-jari).
  - **Mode 3D (Interaktif)**: Menampilkan render proyeksi 3D yang dapat diputar secara bebas menggunakan rotasi mouse (*drag & rotate*).
  - Sinkronisasi mode otomatis di seluruh tab perhitungan.

---

## 🚀 Persyaratan Sistem

- **Python 3.8** atau versi yang lebih baru.
- Modul standar bawaan Python:
  - `tkinter` (GUI desktop)
  - `math` (operasi matematis)
  - `random` (generator soal/angka)
